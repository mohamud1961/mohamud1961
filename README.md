### Mohamud Mohamud

I study why AI agents hand in wrong work they believe is right, from agent traces down to model internals.

- **[unstated-values](https://github.com/mohamud1961/unstated-values):** models give values their context doesn't state. The model's own activations read "not stated" (probe AUROC 1.00), and a probe-gated push cuts copied values 33 → 0 at 7B. Open benchmark, 7-model survey and full report.
- **[core-agent](https://github.com/mohamud1961/core-agent):** a lean agent, with the same passes as Codex on 25 Terminal-Bench 2.1 tasks and 26% cheaper.
- **[Aether](https://github.com/mohamud1961/Aether):** the lab: more than 4,000 graded agent trials, the failure map, and the negative results.
